# Inicio rápido de SIGBO

1. Ejecuta el archivo start-sigbo.cmd desde la carpeta del proyecto.
2. Se instalarán las dependencias si faltan.
3. Se abrirá el frontend en http://localhost:3000.
4. El backend quedará en http://localhost:3001.

Si quieres un acceso directo en el escritorio, crea un acceso directo a start-sigbo.cmd y colócalo en Escritorio.
